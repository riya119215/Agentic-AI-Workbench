# 🏛️ Sovereign Agentic AI Workbench: Technical Architecture Specification

## 1. System Overview & Core Philosophy
The **Sovereign Agentic AI Workbench** is an on-premise, air-gapped agentic operating system engineered specifically for Indian Defence (DRDO, Indian Navy/Airforce/Army), Strategic PSUs (ISRO, ONGC, NTPC, HAL), and Government Ministries.

Unlike public SaaS LLMs, this workbench operates under **Zero-Cloud, Zero-WAN Egress** constraints. It guarantees:
1. **Mathematical Data Sovereignty**: Confidential blueprints, telemetry, and SOPs never leave local server memory.
2. **Autonomous Multi-Step Workflows**: Intelligent decomposition of complex industrial inspection and data analysis tasks.
3. **Formal Deliverables Synthesis**: Generates authentic, audit-compliant `.docx` Note Sheets, `.xlsx` telemetry registers, and `.png` trend diagrams.
4. **Cryptographic Proof of Tamper Resistance**: Immutable SHA-256 blockchain-style hash linked audit logs.

## 2. Multi-Model Tiered Architecture

```
[ Incoming Task / Prompt + Attachments ]
                  │
                  ▼
       ┌────────────────────────┐
       │   Model Auto-Router    │  (model_router.py)
       └──────────┬─────────────┘
                  │
     ┌────────────┼────────────┬────────────┐
     ▼            ▼            ▼            ▼
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ Reasoning│ │  Coding  │ │  Vision  │ │Embedding │
│  Expert  │ │Specialist│ │ Specialist││ Specialist│
│ qwen2.5  │ │qwen2.5-  │ │ qwen2-vl │ │  bge-m3  │
│   (7B)   │ │ coder:7b │ │   (7B)   │ │ (Local)  │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

### Dynamic Routing Logic:
- **Vision Specialist (`qwen2-vl:7b` / `minicpm-v`)**: Triggered for scanned blueprints, thermal imaging, and camera inspection logs.
- **Coding Specialist (`qwen2.5-coder:7b`)**: Triggered for telemetry CSVs, mathematical equations, anomaly detection scripts, and isolated sandbox routines.
- **Reasoning / SOP Expert (`qwen2.5:7b` / `llama3.1:8b`)**: Triggered for clause verification, policy cross-examination, and government approval note drafting.
- **Embedding Specialist (`bge-m3:latest`)**: Multi-lingual dense retrieval with page and paragraph level citations.

## 3. Sandboxed Execution Architecture

To prevent unauthorized remote execution, code generated by models runs in a hardened runtime jail:
1. **Disabled Network Sockets**: Sockets (`socket.socket = None`) are blocked in the interpreter.
2. **Resource Capping**: Hard memory caps (256MB) and execution timeouts (15.0 seconds).
3. **File Isolation**: Restricted write access exclusively to the local scratch workspace.

---

## 4. Cryptographic Audit Trail (SHA-256 Hash Chaining)

Every action (prompt, retrieval chunk, model inference step, file creation, sandbox execution) is committed to an immutable ledger:

$$\text{Block}_{n} = \text{SHA256}(\text{Block}_{n-1}\text{.Hash} \,\|\, \text{Timestamp} \,\|\, \text{User} \,\|\, \text{Payload})$$

If an attacker modifies any historical database record, the entire downstream hash chain is invalidated, triggering an immediate security alert.
